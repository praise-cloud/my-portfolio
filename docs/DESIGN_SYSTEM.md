# Design System — Engineering Editorial

## Creative Direction
"Engineering Editorial" — agency-level craft with the restraint of an infrastructure company.
Synthesis: Kinetic/Gazu scale + Form/Shift structure + Mindly softness in a navy/blue/paper palette.

## Tokens
- `--navy-950`: `#060F1D` (deepest footer/hero dark)
- `--navy-900`: `#0A192F` (primary brand)
- `--slate-700`: `#334155` (secondary)
- `--blue-600`: `#2563EB` (accent: links, dots, active states ONLY - max 5%)
- `--blue-400`: `#60A5FA` (accent on dark backgrounds)
- `--paper`: `#F8FAFC` (soft off-white canvas)
- `--white`: `#FFFFFF`
- `--text-on-light`: `#0A192F`
- `--muted-on-light`: `#64748B`
- `--muted-on-dark`: `#94A3B8`
- `--hairline-light`: `#E2E8F0`
- `--hairline-dark`: `rgba(148, 163, 184, 0.18)`

## Typography
- Display: Manrope 700/800, tight tracking (-0.04em), line-height 0.9–1.0. Sizes: `clamp(3rem, 11vw, 11rem)` for wordmark; `clamp(2rem, 5vw, 4.5rem)` for headlines.
- Body: Inter 400/500, 16–18px, line-height 1.6, max measure 65ch.
- Mono: JetBrains Mono 400, 11–12px uppercase, tracking 0.08em — for metadata, labels, section numbers (001–007), status.
- Accent Serif Italic: Newsreader Italic for single phrase accents.

## Component Inventory
- `Navbar`: Sticky blurred header with "PG" mark, navigation links, live Mauritius/London clock, sound toggle, pill CTA.
- `BentoCard`: Rounded 24–28px cards with 1px hairline border, pill tags, and subtle hover elevation.
- `GlassCard`: White 6% background with backdrop blur 16px and 1px hairline highlight.
- `WordmarkHero`: Giant cropped `PRAISE GEORGEWILL` bleeding off the section edge, layered behind portrait cutout.
- `ProjectShowcase`: 3-mode project viewer (Cinematic Reel, Blueprint Matrix, Editorial Index with floating cursor preview).
- `ProjectDrawer`: Quick-spec slide-out drawer for inspecting case studies without leaving the page.
- `ClusterSimulator`: Live multi-region topology and chaos failover simulator.
- `MarqueeBand`: Monospace technical ribbon between alternating light and dark sections.
