# pg-site-kit
1. Unzip and open this folder as the workspace in Antigravity (desktop or CLI).
2. Put your portrait at public/portrait.png (optional) and fill the placeholders in brand/CONTENT.md with facts you know.
3. Paste the master prompt from PROMPT.md.
Layout note: skills and workflows live in .agents/. If your Antigravity version expects .agent/ (singular), rename the folder. AGENTS.md is also read from the project root.
